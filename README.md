# Qxel Taxonomy for Marketplace

This Taxonomy defines how Qxel Marketplace pages are displayed.

> **Note:** Limiting to **only 3 values** from the same taxonomy per product only, to reduce spam and duplications.

Everyone can contribute.

You can add new Category, edit its taxonomy and do much more.

However, editing existing taxonomy names can affect the pages sometimes.

Like, Taxonomy values are stored in database along with products. But changing taxonomy numbers or doing something like that may do something.

You can add more Items to Taxonomy without an issue.
